## What I'm building

### Vetted Korea · Sourcing Ops Kit *(private, demo on request)*
The operating system behind my buyer-side sourcing and supplier quality service for US hardware companies moving parts to Korean suppliers.

- **Supplier audit form:** 15-item weighted on-site audit (quality system, Cpk and Gauge R&R, change control, lot traceability) with automatic reject on red flags
- **Inspection forms:** first-article (FAI) and pre-shipment (PSI) inspection with **ANSI/ASQ Z1.4** sampling computed from lot size, IPC-A-610 workmanship checks, ICT/functional, hi-pot and burn-in items
- **Landed-cost check:** duty and fees for China, Korea and Vietnam per HTS line, from an approved tariff-rate table
- **Supplier screening:** pension headcount, DART filings and the US Consolidated Screening List, scored automatically
- Stack: PostgreSQL, NocoDB, n8n, Python agents, Cloudflare

### [ReplyPilot Agent](https://github.com/jonggan-kim/replypilot-agent)
Human-approved Gmail reply drafting: classification → draft → review → approval → Gmail draft, with checkpoints and evaluation (LangGraph, LangSmith, FastAPI).
